Cryptocurrency Price Tracker

Project Description

Cryptocurrency Price Tracker is a Python-based web scraping project that collects the latest cryptocurrency price details from CoinMarketCap using Selenium. The collected data is processed using Pandas and stored in an Excel file for easy analysis.

Technologies Used

- Python
- Selenium
- Pandas
- Chrome WebDriver
- Excel

Features

- Scrapes cryptocurrency price details
- Collects data automatically using Selenium
- Processes data using Pandas
- Stores the collected data in an Excel file

Output

The scraped cryptocurrency data is saved in an Excel file named "crypto_prices.xlsx".

Project Purpose

This project was developed to learn Python web scraping, data processing, and automated data collection.
